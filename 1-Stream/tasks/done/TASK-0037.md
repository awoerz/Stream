## Summary
Add a settings section to the app that allows users to input a URL for connecting to a local LM Studio server, ensuring the value is never persisted to disk and must be re-entered on each app startup.

## Acceptance Criteria
- A visible settings location exists in the app with an input field for the LM Studio server URL
- The URL is stored only in memory during runtime and is cleared on app restart
- No URL or related configuration is written to disk, config files, or local storage
- The app prevents accidental persistence (e.g., no inclusion in exported files or commits)
- Basic validation ensures the URL format is correct before use

## Notes
- Use in-memory state (e.g., React state, Electron main process memory, or equivalent)
- Avoid any use of localStorage, filesystem writes, or environment file generation
- Consider a warning or tooltip explaining why the value is not saved
- Ensure this pattern can be extended later for API keys without persistence
