## Summary
After restarting the app, task and bug detail views only display the first list item for acceptance criteria and notes. Additional list items (lines starting with dashes) are not rendered in the UI.

## Acceptance Criteria
- All list items under acceptance criteria are displayed correctly in the task detail view
- All list items under notes are displayed correctly in the task detail view
- Markdown list parsing supports multiple dash-prefixed lines without truncation
- Restarting the app does not affect rendering of multi-line fields
- No regression occurs in preview or other task rendering components

## Notes
- Likely an issue with markdown parsing or splitting logic (e.g., only capturing first match)
- Replaced the regex section parser with line-based heading parsing so multiline sections are read reliably, including the last section in a file.
