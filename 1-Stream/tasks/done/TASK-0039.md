## Summary
Enable sending the generated task prompt to an LM Studio server using the configured URL and return a markdown task file response. The send action should only be available when a valid URL is provided.

## Acceptance Criteria
- A button exists to send the generated prompt to LM Studio
- The button is disabled or hidden when no URL is provided in settings
- The app sends the prompt to the configured LM Studio endpoint successfully
- The response from LM Studio is returned and usable as a markdown task file
- Errors (e.g., invalid URL, connection failure) are handled gracefully and shown to the user

## Notes
- Reuse the existing prompt generation logic for consistency
- Ensure request format matches LM Studio API expectations (likely OpenAI-compatible)
- Validate URL before enabling the send button
- Keep the URL usage in-memory only (do not persist)
- Consider adding loading state or feedback while waiting for response
