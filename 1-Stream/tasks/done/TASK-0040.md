## Summary
Create a new button in the UI that, when clicked, automatically generates and saves a prompting LM Studio task file without displaying the generated prompt or markdown in the interface.

## Acceptance Criteria
- A new button labeled “Generate LM Studio Task” is added to the toolbar.
- Clicking the button creates a file named `prompting_lm_studio_task.md` in the designated output directory.
- The file contains valid Markdown content following the required task template.
- No prompt or markdown preview is shown to the user after clicking; only a confirmation message appears.

## Notes
- Ensure file naming follows the pattern `prompting_lm_studio_task.md` to avoid conflicts.
- The button should be disabled if a file with the same name already exists, or prompt for overwrite confirmation.
- Log the creation event for audit purposes.
