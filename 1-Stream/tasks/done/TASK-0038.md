## Summary
Add right-click (context menu) functionality to the app so users can perform common actions on tasks and UI elements directly from a contextual menu.

## Acceptance Criteria
- Right-clicking on a task or bug opens a context menu with relevant actions
- Context menu includes at least basic actions (e.g., view details, edit, delete)
- Menu appears at the correct cursor position and closes when clicking outside
- Context menu works consistently across supported platforms (Windows/Mac)
- No interference with existing left-click or drag-and-drop behavior

## Notes
- Use Electron’s native context menu API or a custom implementation depending on architecture
- Ensure accessibility and keyboard fallback where appropriate
- Design menu structure to be easily extendable for future actions
- Consider separating menu logic from UI components for maintainability
